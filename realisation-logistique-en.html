Cloud & port logistics case study

Real-time sea freight management

Deployment of a containerised architecture on AWS with a telemetry dashboard and real-time tracking of logistics events for operators at the Port of Douala.

Context & problem

Freight management at the Port of Douala involved many parties (forwarders, shipowners, customs) using disparate systems and exchanging by email and phone. Coordination delays lengthened container stays at the port.

The goal: a unified platform giving a 360° real-time view of freight, automatic alerts and digital coordination between every actor in the logistics chain.

CODE AXIS solution

We built a cloud-native AWS architecture with event-driven services: every container is tracked by IoT sensors, data is centralised in AWS IoT Core, processed by Lambda and visualised in real time on a React dashboard.

A notification system (email, SMS, API webhook) alerts each stakeholder at critical events: arrival, customs clearance, transfer, final delivery.

Technology stack

Next.js FastAPI (Python) AWS IoT Core AWS Lambda Amazon DynamoDB Docker + ECS MQTT Protocol Grafana Dashboards

Project timeline

  • Phase 1: Mapping of existing flows and field interviews with freight forwarders
  • Phase 2: Cloud architecture design and event data model
  • Phase 3: Microservices backend development and IoT integration
  • Phase 4: Real-time analytics dashboard and user interfaces
  • Phase 5: Pilot on a limited scope, adjustments and full rollout

What we delivered

A unified platform gathering freight events in real time, with automatic alerts and digital coordination between forwarders, shipowners and customs. The telemetry dashboard gives operators a shared view of the logistics chain.
