🎯 Contexte & Problématique

Un grossiste camerounais souhaitait passer d'une activité physique à une présence digitale complète, permettant aussi bien aux particuliers d'acheter en ligne qu'aux revendeurs B2B de passer des commandes en gros avec des tarifs différenciés.

Le défi majeur : intégrer les paiements mobiles locaux (Orange Money, MTN MoMo), souvent indisponibles dans les solutions e-commerce occidentales, tout en supportant un catalogue de plus de 8 000 produits.

💡 Solution CODE AXIS

Nous avons développé une marketplace multi-vendeurs avec double espace client (B2B et B2C), des API de paiement local propriétaires, et une application mobile dédiée aux livreurs permettant de gérer les tournées et les confirmations de livraison en temps réel.

Le système de gestion de stocks multi-entrepôts synchronise automatiquement les disponibilités entre la boutique en ligne et les points de vente physiques.

🛠️ Stack Technologique

Next.js 14 Node.js + NestJS MongoDB React Native Orange Money API MTN MoMo API Redis AWS S3 + CloudFront

📋 Déroulement du Projet

  • Phase 1 : Ateliers UX avec le client et ses revendeurs clés, benchmarking solutions locales (2 semaines)
  • Phase 2 : Conception des maquettes Figma haute fidélité et validation client (3 semaines)
  • Phase 3 : Développement plateforme web B2B/B2C et intégration paiements locaux (10 semaines)
  • Phase 4 : Application mobile livreurs et tableau de bord logistique (4 semaines)
  • Phase 5 : Tests bêta avec 20 marchands pilotes, corrections et déploiement (3 semaines)

✅ Résultats Obtenus

La plateforme a atteint 320 marchands actifs en seulement 4 mois, avec plus de 45 000 commandes livrées. Le chiffre d'affaires du client a été multiplié par 5,2 grâce à l'ouverture au marché national.

La note de 4.9/5 sur le Play Store valide la qualité de l'expérience utilisateur, et le taux de réachat a atteint 68% dès le 3ème mois.
