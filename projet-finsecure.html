FinSecure Cameroun

Application de paiement sécurisé multi-banques avec authentification biométrique et détection de fraudes par intelligence artificielle.

Déployé en Production
🔐

🚀 Description du Projet

FinSecure est une application mobile permettant aux utilisateurs camerounais de gérer l'ensemble de leurs comptes bancaires depuis un seul endroit, d'effectuer des virements instantanés et de payer en ligne en toute sécurité.

Le moteur d'IA embarqué analyse en temps réel les patterns de transaction pour détecter les comportements frauduleux et bloquer automatiquement les opérations suspectes avant leur validation.

⚡ Fonctionnalités Clés

🏦

Multi-banques

Agrégation de comptes de toutes les banques partenaires en une interface unique

👆

Biométrie

Authentification empreinte digitale et reconnaissance faciale ultra-sécurisée

🤖

IA Anti-Fraude

Modèle ML analysant 150+ signaux de fraude en moins de 200ms par transaction

📲

Paiements QR

Paiement instantané en point de vente par QR code sécurisé dynamique

🛠️ Technologies Utilisées

React Native Node.js PostgreSQL TensorFlow.js Biometrics API AES-256 Encryption AWS Cognito ISO 27001
